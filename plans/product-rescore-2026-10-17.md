## 2. 本轮实际修掉的问题（映射首轮 P0/P1，附真机复验证据）

### ✅ P0④ 概览缩放下时间线是实心色块 → 已修复（核心价值失效解除）
- `src/timeline/density.ts`：`densityAlpha(c, expected)` 以「常态速率」为 0 点做 log2 映射，均匀数据不再全饱和。
- `LogStreamView` 顶栏加「🔥 跳到最密集时段」按钮；`TimelineCanvas` / `renderers.ts` 全走密度色。
- **真机复验**：全量窗（206.8h / 26.8 万命中）密度条饱和率 **100% → 0%**（12 档、p50=0.506）；点「最密集」后窗宽 **206.8h → 24.2m**，alpha 动态范围 0.247→0.92。
- 「垂直对齐看关联」在默认缩放**终于可用**。

### ✅ P0③ 分析结果出不去（最后一公里）→ 已修复
- `src/io/exportMd.ts` / `exportFile.ts` / `exportActions.ts`：选中链/事件 → Markdown（含文件 / 行号 / 时间），命中可导出。
- `CommandPalette` 新增「导出」组 6 条命令。

### ✅ P0② 规则资产出不了工作区（GUI 层）→ 已部分修复
- `src/io/rulesIo.ts`：`.loggraph.json` 互导 + `.cep.json` 导出（逐条警告引擎 v1 不支持的 W01/W02/W03/W04/W05/scope:message）。
- GUI 现在有导入/导出入口，规则可跟代码仓库走、进 CLI 校验链路。
- 注：CLI 侧 schema/validate 早已就绪；本轮补的是 GUI 这一半。

### ✅ 附A② 异常数字自相矛盾 → 已修复
- `src/utils/counts.ts`：`trueChainCount` / `trueUncoveredCount` 取 `total*` 真值，而非被 `CEP_MAX_CHAINS=2000` 截断的 `.length`。
- 上游 `NodeCanvasView` / `GroupMatchesTab` / `CepTimelinePanel` / `DetailPanel` / `TimelineCanvas` 全部改走真值。
- **真机复验**：两处一致显示「**1615 链 · 33.6万 异常**」（旧版画布头部错显 2000）。

### ✅ P2④ 深色主题 MiniMap / Controls 白框 → 已修复
- `NodeCanvasView.module.css` 追加 `--xy-minimap-*` / `--xy-controls-*` 深色接管。
- **真机复验**：MiniMap/Controls 背景 rgb(26,33,48)，融入深色画布。

### ✅ P1⑦ 无 CI / 前端零测试 / 无 LICENSE → 已修复
- `.github/workflows/ci.yml`：前端 `tsc -b` + `vitest` + `build`；Rust `engine + cli` 单测。
- `LICENSE`（MIT）、`vitest.config.ts`、`src/**/*.test.ts` 共 **45 个前端测试**（counts / density / hotspots / rulesIo / exportMd）。
